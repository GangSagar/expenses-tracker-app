# Orchestrator Example

**Task:** “Add an export feature.”

**Assignment:** Graphify maps transaction and settings boundaries; Planning writes a scoped plan; Architecture joins only if the export affects persistence/contracts; Implementation owns the approved source changes; Testing verifies export formats and privacy; Documentation updates user guidance.

**Final report:** outcome, changed areas, exact verification performed, and any unsupported formats or remaining decisions. Do not claim export is released unless it was actually released.
