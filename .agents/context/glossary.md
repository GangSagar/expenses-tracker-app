# Project Glossary

- **Message**: an SMS or supported notification payload processed by the app.
- **Parser**: deterministic extraction of transaction fields from a message.
- **Candidate**: structured parser output before the decision policy accepts or rejects it.
- **Decision policy**: application rule that chooses save, review, or reject behavior.
- **Transaction application**: shared application boundary coordinating transaction flows and use cases.
- **Repository**: persistence port/adapter boundary for local transaction storage.
- **Model catalog**: available local inference model definitions; currently empty per architecture documentation.
- **Graphify**: repository knowledge graph used for focused structure/dependency queries.
