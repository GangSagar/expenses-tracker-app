# Project Memory

Durable, evolving project state lives here. Keep entries factual, dated when useful, and concise. Link canonical docs and source locations. Do not put raw user data, secrets, speculative plans, or generated graph dumps here.

- `project_summary.md`: purpose, stack, major modules, current supported state.
- `decisions.md`: durable decisions and their rationale.
- `current_tasks.md`: active work only; remove or archive stale entries during maintenance.
- `known_bugs.md`: confirmed defects and status; do not duplicate general backlog items.
- `api_contracts.md`: stable external or cross-module contracts; mark absent/unverified contracts clearly.
- `architecture_snapshot.md`: concise, manually curated orientation; canonical detail remains in `docs/ARCHITECTURE.md`.
- `dependency_graph.md`: instructions and link to Graphify outputs, not a copied generated graph.
