# Security and Data Handling

- Treat SMS, notifications, contact details, logs, test corpus, model files, and user financial records as sensitive.
- Do not place personal or raw transaction data in prompts, artifacts, logs, screenshots, or reports unless necessary and authorized; redact identifiers where possible.
- Keep credentials and signing material out of source control and generated reports.
- For support reporting or telemetry, inspect consent, minimization, retention, transport, and failure behavior before changing the data flow.
- Report security concerns with impact and a concrete mitigation; do not claim a security audit from a narrow review.
