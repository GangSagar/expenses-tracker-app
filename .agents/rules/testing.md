# Testing and Verification

- Choose checks that exercise the changed behavior and report the exact command and result.
- Add regression coverage for a bug fix when implementation work is authorized.
- Separate unit, integration, device, and manual verification; do not claim one substitutes for another.
- Do not claim a test passed unless it was run and its output supports that claim.
- Before commit or push, follow the repository-wide test requirement in `.agents/AGENTS.md`.
- Respect the user’s request about whether to run verification; report unverified risks clearly.
