# Git and Change Ownership

- Never commit or push unless the developer directly asks.
- Keep changes scoped to the requested task and preserve unrelated working-tree changes.
- Do not include secrets, local datasets, downloaded models, generated build output, or private user data in changes.
- Use `type(scope): summary` when the developer asks for a commit.
- Before any requested commit or push, follow the full verification gate in `.agents/AGENTS.md`.
